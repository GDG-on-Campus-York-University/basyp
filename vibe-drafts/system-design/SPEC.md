# Sample portfolio spec (gallery example, fictional student)

<!-- GALLERY SAMPLE. Mateo Fischer and these projects are made up for the vibe gallery. Use this file as the content source for this sample site only. -->

- **Who I am:** Mateo Fischer, third-year Software Engineering student at York University.
- **Audience and goal:** I want co-op employers to see that I think about how the parts of a program fit together before I write the code.
- **About me:** I like to draw the pieces of a program on paper first: what talks to what, and where the data lives. Then I build it one piece at a time and write tests as I go. I am happiest when a project is small enough to finish and clear enough that a teammate can pick it up.
- **Sections:** Home, About, Projects, Skills, Contact.
- **Projects:**
  - Study Room Booker: a small web service for booking study rooms, with a Python (Flask) back end, a SQLite database and a plain JavaScript page. Built with a team of four for a software design course. Link: https://example.com/mateo-fischer/study-room-booker (label: Source code).
  - Chat Room: a chat server and client in Java that use sockets and threads, so several people can talk at once. Made for an operating systems course.
  - Recipe Box: a command-line recipe manager in Python that stores recipes in a plain text file, with unit tests. My first project with a test suite.
- **Skills:** Java, Python, JavaScript, SQL, Flask, JUnit, unit testing, Git, Linux command line.
- **Contact:** mateo.fischer@example.com; GitHub: https://example.com/mateo-fischer.
- **Vibe and feel:** `vibe-system-design`: structured, clear, careful.
