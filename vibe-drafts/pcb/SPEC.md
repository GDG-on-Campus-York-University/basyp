# Sample portfolio spec (gallery example, fictional student)

<!-- GALLERY SAMPLE. Daniel Osei and these projects are made up for the vibe gallery. Use this file as the content source for this sample site only. -->

- **Who I am:** Daniel Osei, second-year Computer Engineering student at York University.
- **Audience and goal:** I want co-op employers to see that I design, solder and debug my own embedded hardware.
- **About me:** I like projects where code and hardware meet: choosing the parts, laying out the board, soldering it, and then working out why it does not behave. I am happiest with a multimeter in one hand and a datasheet open.
- **Sections:** Home, About, Projects, Skills, Contact.
- **Projects:**
  - Plant Monitor: a battery-powered soil moisture sensor on a small custom board that wakes up, reads the soil and sends the result to my phone over Bluetooth.
  - Logic Probe: a pocket tool I built for my digital logic course. It shows whether a pin is high, low or floating using three LEDs, and it lets me check circuits without an oscilloscope. Link: https://example.com/daniel-osei/logic-probe
  - Reaction Timer: a two-player reaction game on a microcontroller, with a button for each player, a display for the score and a buzzer, written in C.
- **Skills:** C, Python, Arduino, KiCad, soldering, breadboard prototyping, multimeter debugging.
- **Contact:** daniel.osei@example.com; GitHub: https://example.com/daniel-osei; LinkedIn: https://example.com/daniel-osei-profile.
- **Vibe and feel:** `vibe-pcb`: careful, hands-on, hardware.
