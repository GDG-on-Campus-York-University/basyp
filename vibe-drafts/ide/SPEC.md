- **Audience and goal:** I want internship recruiters to see that I write clear code, test it and keep my projects tidy.
- **About me:** I like reading a problem twice before I write any code, then building the solution in small pieces and running it after every change. I enjoy tidying a program once it works, so that the next person can read it, and that next person is usually me a month later.
- **Sections:** Home, About, Projects, Skills, Contact.
- **Projects:**
  - Study Timer: a small website built with HTML, CSS and JavaScript that counts down focused study sessions and keeps a list of the finished ones in the browser. Link: https://example.com/rhea-castellanos/study-timer.
  - Maze Solver: a Python program that reads a maze from a text file and prints the shortest path through it using breadth-first search, written for a data structures course.
  - Library Catalogue: a Java command-line program for a databases course that stores books in a SQLite database and lets me search them by title or author.
- **Skills:** Python, Java, JavaScript, SQL, HTML and CSS, Git and GitHub, command line.
- **Contact:** rhea.castellanos@example.com; GitHub: https://example.com/rhea-castellanos.
