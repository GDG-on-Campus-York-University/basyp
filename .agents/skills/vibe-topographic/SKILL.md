# Vibe: Topographic

## Feel and who it's for
The portfolio reads like a printed survey sheet: pale stone paper, fine taupe contour lines that trace invisible hills behind the content, dark ink for text and one lake blue for links. It is patient, exact and quietly outdoorsy. The lines are generated by a small function, never an image. Good for geomatics, geography, environmental and earth science students who want a co-op employer to see "this person turns field measurements into a clear map".

## Must keep (this is what makes it Topographic)
1. A contour field drawn as SVG from a deterministic height function (a few smooth hills added together). Same numbers, same map, every load. Every fifth line is heavier, like an index contour.
2. Quiet colour: stone paper, ink text, taupe lines (decoration only, never text) and ONE lake-blue accent for links, focus and the current section.
3. Lines never fight the text. They stay far fainter than any word and pass behind the content.
4. Motion is slow and geological: lines draw outward from a summit, rules draw along a ridge, nothing bounces. Only the map itself reacts to the cursor, and only a little.
5. No survey data. No elevations, coordinates, bearings, scale bars with distances or spot heights. Any map label is `aria-hidden` and is a real section name.

## Starting defaults (change freely)
The student can say "make the lines greener" or "use the night map". Their request wins.

Palette, in words: stone paper (grey with a warm hint, not cream), a slightly lighter sheet for cards, green-black ink, a mid slate for secondary text, taupe and darker umber for contour lines, a deep lake blue for links.

## Make it theirs
- The one loud thing is the hero contour field. The other four moments stay small: a ridge rule, a thin underline, a nested outline.
- Their fieldwork sets the details: tools and courses become the skills and project titles. A real place the student names in SPEC.md may appear as plain text, but never draw its real coastline, elevations or coordinates.
- They can reshape the land by editing `PRESETS` (hill positions, number of lines). Keep the summit away from the text.

## Motion character
Tempo: geological, 1200 to 2600 ms for the drawing, 240 to 420 ms for small UI changes. Easing: `var(--ease-ridge)` for every CSS motion; the cursor drift is a lerp (7% of the gap per frame), not CSS easing. Things draw, fade or shift a few pixels; they never bounce, spin or loop. Text, cards and the nav never move. Only `transform`, `opacity` and `clip-path` animate. JavaScript may set inline styles (the drift's `transform`, `--sx`, `--sy`, `--header-h`); that is allowed. The JavaScript snippets share one `script.js`: put the helpers first, then each moment in order.

Shared keyframes (used by several moments, keep them together):
```css
@keyframes bloom { from { clip-path: circle(0% at var(--sx, 70%) var(--sy, 40%)); } to { clip-path: circle(150% at var(--sx, 70%) var(--sy, 40%)); } }
@keyframes survey { from { clip-path: inset(0 100% 0 0); } to { clip-path: inset(0 0 0 0); } }
@keyframes arrive { from { opacity: 0; } to { opacity: 1; } }
```

Shared JavaScript: the height function, the contour tracer (marching squares) and the presets. Hills are `[x, y, spread, height]` in a 0 to 1 box; the first hill is the summit.
```js
const motion = window.matchMedia('(prefers-reduced-motion: reduce)');
const SVG_NS = 'http://www.w3.org/2000/svg';
// Keep cols / rows at 1.6 (the grid is stretched to the screen, so a different ratio squashes the rings).
const PRESETS = {
  hero: { cols: 120, rows: 75, levels: 14, hills: [[0.7, 0.4, 0.2, 1], [0.45, 0.68, 0.16, 0.7], [0.92, 0.82, 0.14, 0.55], [0.2, 0.3, 0.15, 0.45]] },
  page: { cols: 112, rows: 70, levels: 9, hills: [[0.2, 0.25, 0.3, 1], [0.78, 0.6, 0.26, 0.8], [0.4, 0.92, 0.22, 0.6]] },
};
// Decoration only: smooth hills plus a little ripple, so the lines are not perfect circles. No real terrain.
function heightAt(x, y, hills, aspect) {
  let z = 0.04 * Math.sin(9 * x + 4 * y) * Math.cos(7 * y);
  for (const [hx, hy, spread, peak] of hills) {
    const dx = (x - hx) * aspect, dy = y - hy;
    z += peak * Math.exp(-(dx * dx + dy * dy) / (2 * spread * spread));
  }
  return z;
}
// Edges of one grid cell: 0 top, 1 right, 2 bottom, 3 left. Each case lists which edges a line joins.
const CASES = [[], [[3, 2]], [[2, 1]], [[3, 1]], [[0, 1]], null, [[0, 2]], [[0, 3]], [[0, 3]], [[0, 2]], null, [[0, 1]], [[3, 1]], [[2, 1]], [[3, 2]], []];
function buildField(svg, { cols, rows, levels, hills }) {
  const aspect = cols / rows, stride = cols + 1, z = [];
  for (let j = 0; j <= rows; j++) for (let i = 0; i <= cols; i++) z.push(heightAt(i / cols, j / rows, hills, aspect));
  const lo = Math.min(...z), hi = Math.max(...z);
  svg.setAttribute('viewBox', `0 0 ${cols} ${rows}`);
  svg.setAttribute('preserveAspectRatio', 'xMidYMid slice');
  for (let k = 0; k < levels; k++) {
    const t = lo + ((hi - lo) * (k + 1)) / (levels + 1);
    let d = '';
    for (let j = 0; j < rows; j++) for (let i = 0; i < cols; i++) {
      const a = z[j * stride + i], b = z[j * stride + i + 1], c = z[(j + 1) * stride + i + 1], e = z[(j + 1) * stride + i];
      const index = (a >= t ? 8 : 0) + (b >= t ? 4 : 0) + (c >= t ? 2 : 0) + (e >= t ? 1 : 0);
      let joins = CASES[index];
      if (!joins) { // the two saddle cases: the cell centre decides which way the lines run
        const centreHigh = (a + b + c + e) / 4 >= t;
        joins = (index === 5) === centreHigh ? [[0, 3], [2, 1]] : [[0, 1], [3, 2]];
      }
      const point = (edge) => [
        [i + (t - a) / (b - a), j], [i + 1, j + (t - b) / (c - b)], [i + (t - e) / (c - e), j + 1], [i, j + (t - a) / (e - a)],
      ][edge].map((n) => n.toFixed(2)).join(' ');
      joins.forEach(([from, to]) => { d += `M${point(from)}L${point(to)}`; });
    }
    const path = document.createElementNS(SVG_NS, 'path');
    path.setAttribute('d', d);
    path.setAttribute('class', k % 5 === 4 ? 'contour contour-index' : 'contour'); // every fifth line is heavier
    svg.appendChild(path);
  }
  // The "bloom" in moment 1 starts under the summit.
  svg.parentElement.style.setProperty('--sx', hills[0][0] * 100 + '%');
  svg.parentElement.style.setProperty('--sy', hills[0][1] * 100 + '%');
}
document.querySelectorAll('svg.field[data-preset]').forEach((svg) => buildField(svg, PRESETS[svg.dataset.preset]));
```

### 5. Signature: the drifting map
The contour field (moment 1) is the signature: it blooms once, then the map shifts a few pixels as the mouse moves, the hero field further than the page field, so the layers feel like different depths. Only for a fine pointer (mouse or pen) and only without reduced motion. Touch screens get a still map. The loop eases toward the target, writes transforms only (all numbers are read once, outside the loop) and stops itself when settled.

```js
const fine = window.matchMedia('(pointer: fine)');
const layers = [...document.querySelectorAll('.field[data-depth]')].map((el) => ({ el, depth: Number(el.dataset.depth) }));
const pos = { x: 0, y: 0 }, target = { x: 0, y: 0 };
let frame = 0, vw = window.innerWidth, vh = window.innerHeight;
function drift() {
  pos.x += (target.x - pos.x) * 0.07; pos.y += (target.y - pos.y) * 0.07;
  const settled = Math.abs(target.x - pos.x) < 0.002 && Math.abs(target.y - pos.y) < 0.002;
  if (settled) { pos.x = target.x; pos.y = target.y; }
  layers.forEach(({ el, depth }) => { el.style.transform = `translate3d(${(pos.x * depth).toFixed(2)}px, ${(pos.y * depth).toFixed(2)}px, 0)`; });
  frame = settled ? 0 : requestAnimationFrame(drift); // no loop while nothing moves
}
function aim(x, y) { target.x = x; target.y = y; if (!frame) frame = requestAnimationFrame(drift); }
function onMove(event) { if (event.pointerType !== 'touch') aim((event.clientX / vw) * 2 - 1, (event.clientY / vh) * 2 - 1); }
function onLeave() { aim(0, 0); }
function setDrift() {
  const on = fine.matches && !motion.matches;
  window[on ? 'addEventListener' : 'removeEventListener']('pointermove', onMove, { passive: true });
  document.documentElement[on ? 'addEventListener' : 'removeEventListener']('mouseleave', onLeave);
  if (!on) { cancelAnimationFrame(frame); frame = 0; pos.x = pos.y = target.x = target.y = 0; layers.forEach(({ el }) => { el.style.transform = ''; }); }
}
window.addEventListener('resize', () => { vw = window.innerWidth; vh = window.innerHeight; });
fine.addEventListener('change', setDrift);
motion.addEventListener('change', setDrift);
setDrift();
```
Stay subtle: the deepest layer moves 18px at most. Never tie the drift to scroll, and never move text with it.
When you screenshot the page: the fixed page field shows in every viewport shot (that is correct), and the drift shifts the lines if the mouse is not parked, so park it in a corner and wait about 3 seconds for the bloom.

## Libraries
None. Plain CSS, JavaScript and SVG.

## Avoid
- Elevations, coordinates, bearings, scale bars with distances, spot heights, legend swatches or any number on the map. Labels only if `aria-hidden` and a real section name.
- A contour image or screenshot of a real map (the lines come from the function), or busy, high-contrast lines under body text.
- A third accent (no green forests, red roads or blue water fills), or lake blue on long text.
